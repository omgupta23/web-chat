# 💬 Chat App

A real-time chat application built using React, Node.js, Express, MongoDB, and Socket.IO.

## Features

* User Signup & Login
* JWT Authentication
* Real-Time Messaging
* Private Chat
* Online / Offline Status
* MongoDB Database

## Tech Stack

### Frontend

* React.js
* Axios
* React Router
* Socket.IO Client

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* Socket.IO
* JWT
* bcrypt

## Installation

### Backend

```bash
cd Backend
npm install
npm run dev
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

## Environment Variables

Create a `.env` file:

```env
PORT=5000
DB_CONNECTION_SECRET=your_mongodb_url
JWT_SECRET=your_secret_key
```
